# Sons de la roue

Remplace ces fichiers par tes propres sons (mêmes noms, ou change les chemins dans `src/components/wheel/Wheel.tsx` et `src/components/tournoi/PoulainDorReveal.tsx`) :

- `wheel-spin.mp3` — joué pendant la rotation de la roue.
- `poulain-dor.mp3` — joué lors de l'animation du Poulain d'Or.

Aucun fichier n'est fourni par défaut : tant qu'ils sont absents, le site fonctionne normalement (l'échec de lecture audio est silencieusement ignoré).
